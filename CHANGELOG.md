# Changelog

## 0.1.0 - 2026-09-23

- Add typed Go APIs for Choice, Score, Noul, and ordered mixed prediction.
- Add verified local directory, Hugging Face snapshot-layout, and `fs.FS`
  bundle sources with explicit caller ownership.
- Add the opt-in, pinned linux/amd64 FP32 native configuration and protected parity,
  cancellation, lifecycle, race, and RSS evidence.
- Add optional Google ADK Go v2.4.0 typed data and deterministic routing nodes.
- Add directory, embedded-filesystem, and shared-model ADK compositions.

This release does not acquire models, provide a server, support ADK v1, or
claim application suitability or unqualified platform/precision/provider use.
